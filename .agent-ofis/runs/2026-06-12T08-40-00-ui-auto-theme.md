# Run — Sistem teması otomatik algılama

## Yapılan (kullanıcı: "Sistem temasını otomatik algıla")
- `themeMode.tsx` — ilk açılış: `savedMode() ?? (systemPrefersDark() ? 'dark' : 'light')`.
- `isAuto` state: localStorage'da tercih yoksa true.
- Auto modda `matchMedia('(prefers-color-scheme: dark)')` **change** dinlenir → sistem değişince canlı döner. Kullanıcı toggle'ladığında listener kalkar.
- `setMode/toggle` → `localStorage('og_theme')` yazar + `isAuto=false` (kalıcı override).

## Davranış
- İlk ziyaret → cihaz/sistem temasına uyar (persist yok).
- Kullanıcı toggle → tercih kalıcı, artık sistemden bağımsız.

- web tsc ✅ · web build ✅ · **canlı DOM** ✅ (og_theme silince sistem=dark→app=dark, stored null; toggle→light persist, sistem dark olsa da izlemeyi bıraktı) · konsol temiz
