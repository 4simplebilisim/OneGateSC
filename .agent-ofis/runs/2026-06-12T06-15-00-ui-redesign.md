- **`web/src/theme.ts`** (YENİ): tam AntD 6 token seti — renk/tipografi/yarıçap(9)/elevation + **18 komponent override** (Layout/Menu/Table/Card/Button/Input/Select/Statistic/Tag/Segmented/Tabs/Modal/Form/Tooltip…). `BRAND` + `FONTS` export.
- **Marka fontu**: Inter (gövde) + Plus Jakarta Sans (başlık) — index.html Google Fonts, styles.css'te başlıklara display font.
- **`styles.css`** → design-system: yuvarlatılmış (12px) gölgeli tablolar, yumuşak kart elevation+hover, `.og-page` ritmi, `.og-pageheader` deseni, `.og-stat` accent kartı, scrollbar, sticky header/sider.
- **`PageHeader.tsx`** (YENİ): marka çizgisi + başlık + alt açıklama + sağ aksiyon — standart.
- **GenericList**: 5 dolgu-renkli buton → **tek primary "Yeni"** + sakin `text` aksiyonlar (İzle/Düzenle/Sil); standart başlık + kayıt sayısı; boş durum (Empty); boolean → **Evet/Hayır rozet**.
- **Dashboard**: ikonlu, accent-soft stat kartları; valueStyle→styles.content (deprecation temiz).
- **main.tsx**: tema + `tr_TR` locale bağlandı. **Shell**: sticky header/sider, 56px hizalama.
