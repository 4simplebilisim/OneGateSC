# Kullanıcı Yönetimi + Yetkiler

İstek: kullanıcı yönetim ekranı yoktu (route var, UI yok). Kullanıcı **firma/tesis/depo/operasyon** yetkileri için ekran. Kullanıcı kararları: **enforcement şart (net çözüm)**, **firma = kullanıcı alanı** (ayrı çoklu-firma yetkisi yok → scope ekranı Tesis/Depo/Operasyon).

## Legacy
`TBLKULLANICIYETKI`/`...DETAY` generic (kullanıcı↔yetki tipi↔kod). Klonlamadan temiz uygulandı: tek generic `TBLUSERAUTHORIZATION` (scopeType enum + referenceId).

## Backend
- **Şema** (migration `20260622073130`): `TBLUSERAUTHORIZATION` (companyId, userId, **scopeType** `UserScopeType` FACILITY/WAREHOUSE/OPERATION_TYPE, referenceId, isActive, `@@unique([userId,scopeType,referenceId])`) + TBLUSER/TBLCOMPANY ilişkileri.
- **[[src/lib/userAuth.ts]]** `assertUserAuthorized` — kısıtlama-listesi modeli: bir scope tipinde hiç kayıt yoksa serbest; varsa yalnız listedekiler. **super-admin bypass**. Tesis deponun facilityId'si üzerinden kontrol edilir.
- **[[src/routes/userAuthorizations.ts]]** CRUD (admin-only, ?userId&scopeType filtre, referenceId firma doğrulamalı — cross-tenant koruması).
- **[[src/routes/users.ts]]**: +PATCH (ad/eposta/rol/firma/aktif + şifre reset), +DELETE (belge geçmişli kullanıcı → temiz **409**, P2003 yakalanır), companyId super-admin'de seçilir, GET/:id tenant süzmesi, super-admin düzenle/sil koruması.
- **[[src/routes/companies.ts]]** (yeni) GET /api/companies (firma alanı için; super-admin tüm, normal admin kendi).
- **[[src/routes/documents.ts]]**: belge oluştururken `assertUserAuthorized(warehouseId, operationTypeId)` → yetkisiz **403**.

## Frontend
- **Kullanıcılar** ekranı (Uyarlamalar > Sistem): GenericList + **[[web/src/pages/UserForm.tsx]]** (kullanıcı adı/ad soyad/eposta/şifre/**firma**/roller/aktif; edit'te şifre opsiyonel reset).
- **[[web/src/pages/UserAuthorizations.tsx]]** — liste "Yetkiler" butonu → 3 bölüm (Tesis/Depo/Operasyon), her biri çok-seçimli; seçim diff'i ile POST/DELETE; boş=serbest etiketi.
- GenericList: users CREATE_PAGES/canEdit/DELETE_OK + "Yetkiler" butonu; PRETTY Türkçe kolonlar.
