# Giriş menüsü eksik ekranlar (StokBar parite)

İstek: Giriş alt-menüsünde eksik ekranlar (iş atama gibi) → İş Atama, Stok Giriş, Giriş Etiketleme eklendi. Kullanıcı her birinin davranışını netleştirdi.

## Yapıldı
- **İş Atama** — `TBLDOCUMENTASSIGNMENT` (belge↔kullanıcı eşleştirme, plain Int), migration `20260620053000`. Backend [[src/routes/assignments.ts]] (simpleCrud). UI: generic form (Belge ref + Kullanıcı ref + Not). Amaç: terminalde kullanıcıya atanmış belge gözükecek (legacy TBLSBBELGEBASLIK=bizde TBLDOCUMENT).
- **Stok Giriş** — [[web/src/pages/StockEntry.tsx]] (özel ekran, Belge'den AYRI): Tesis/Operasyon seç → barkod okut (`/api/lookup/barcode`) ya da rehberden ürün → satırlar (ürün/birim/miktar/lokasyon/parti/seri) → create+confirm+complete (stok yazılır).
- **Giriş Etiketleme** — [[web/src/pages/EntryLabeling.tsx]]: giriş belgesi seç → ürünler → etiket tipi → **Etiket Bas** (code128Svg ile yazdırma penceresi).

- Ref-etiket fallback genişletildi: code/name yoksa **documentNo/username**/description.
