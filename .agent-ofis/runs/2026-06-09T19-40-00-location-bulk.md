# Run — Seviye-bazlı toplu lokasyon üretme

Kullanıcı StokBar lokasyon ekranını gösterdi: seviye-bazlı kırılımla (Seviye 1-4 × Başlangıç/Bitiş/Artış) toplu lokasyon ekleme. Yeni tablo yok — mevcut TBLLOCATION'a üretici.

## Yapıldı
- ⚡ Backend — `POST /api/locations/bulk-generate`: her seviye start/end/increment → kartezyen çarpım, sıfır-dolgulu kod (end genişliğine göre), önek (göz kodu) + ayraç, duplicate atlar (createMany skipDuplicates), 5000 limit. Yanıt: {requested, created, skipped, sample}.
- 🎨 Frontend — `LocationBulkGenerate.tsx`: depo seç + göz kodu + ayraç + seviye sayısı (1-4) + **Başlangıç/Bitiş/Artış matrisi** + **canlı önizleme** (kaç lokasyon + örnek kodlar). Locations toolbar'ına "Toplu Üret" butonu.

## Doğrulama
- typecheck ✅ · Bulk E2E 7/7 (6 üret, sıfır-dolgu end=10→2hane, duplicate-atla, 5000 limit, VIEWER 403) ✅ · UI build ✅
- eval: matris + Göz Kodu + canlı önizleme "30 lokasyon" (3×10) render.
