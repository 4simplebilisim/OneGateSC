# Saha Tanımı + Belge/Gözlem

İstek: Ek Saha + Statik Ek Saha → TEK menü (Tip=Dinamik/Statik zorunlu); Operasyon Tipi Saha Bağlantı; Giriş/Çıkış/Transfer için Belge (kopyala) + Gözlem (izleme) ekranları.

## Yapıldı
- **Şema** (3 model, wms): `TBLEXTRAFIELD` (Dinamik+Statik birleşik, `fieldKind` ayırt-edici), `TBLEXTRAFIELDOPTION` (seçenek), `TBLOPERATIONTYPEEXTRAFIELD` (op-bağlantı). 3 enum (ExtraFieldKind/Entity/DataType — string). Migration `20260620050748_extra_field_saha` (diff+deploy runbook, BOM yok).
- **Backend**: [[src/routes/extraFields.ts]] (3 simpleCrud) + [[src/routes/documents.ts]] `POST /:id/copy` (başlık+satır kopyala → yeni DRAFT + belge no).
- **Frontend**: Ek Saha tek-ekran formu (Tip=Dinamik/Statik + Uygulama Yeri + Ek Saha Özelliği + min/max + switch'ler); Saha Tanımlamaları menü grubu (Ek Saha + Operasyon Tipi Saha Bağlantı); İşlemler her yön = **Belge** (Yeni+Belge Kopyala) + **Gözlem** (observe salt-okunur, sadece İzle + durum segmenti). `ResourceDef.observe`; GenericList observe-gating + Belge Kopyala. Ref-etiket fallback (code/name yoksa description) — Ek Saha ref'i için.
- enum→etiket: formConfig select options + GenericList `selectLabelMap`.
