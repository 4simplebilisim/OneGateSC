# Run — DB kalıcı çözüm (self-heal watchdog)

Demo riski #1 (Docker/DB oturum-arası kapanması) kalıcı çözüldü.

## Neden native PG değil
PostgreSQL 18 native kurulu ama pg_hba scram-sha-256 + superuser şifresi yok; scheduled task oluşturma da bu ortamda "Access denied". Bu yüzden admin/şifre gerektirmeyen, kanıtlı bir self-heal kuruldu.

## Çözüm — 4 katman
1. **Watchdog** (`scripts/db-watchdog.ps1`): sonsuz döngü, her 60 sn Docker daemon + onegate-db container'ını garanti eder; daemon kapalıysa Docker Desktop'ı başlatır.
2. **HKCU Run anahtarı** (`OneGateDBWatchdog`): watchdog her login'de otomatik (hidden) başlar — admin gerekmez.
3. **Docker AutoStart=true** (settings-store.json): Docker Desktop login'de başlar.
4. **compose restart: unless-stopped**: container daemon ile birlikte geri gelir.

## Kanıt
- Self-heal testi: `docker stop onegate-db` → ~35 sn içinde watchdog **geri getirdi** (Up, accepting connections). ✅
- watchdog süreci aktif; API/UI/DB ayakta (200/200/up).

## Not
Docker AutoStart Docker tarafından bazen False'a ezilebiliyor — watchdog zaten Docker'ı kendisi başlattığı için sorun değil. Tek artık risk: watchdog sürecinin öldürülmesi (login'de tekrar başlar).
